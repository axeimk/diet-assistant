# フィードバックの実装名も`feedback`に統一する

- ステータス: 承認済み
- 日付: 2026-07-26

利用者向けの正規用語を「フィードバック」にした後も、CLI・Python・JSON・設定・DBでは
`advice`が残り、同じ概念を探す際に2語を使い分ける必要があった。公開境界と内部識別子を
`feedback`へ統一し、旧CLI名と旧設定キーの互換別名は残さない。既存DBの記録だけは
マイグレーション10で`feedback_history`へ移し、内容を保持する。

## 検討した代替案

- **旧名を互換別名として残す** — 既存の呼び出しは動き続けるが、コード探索と文書では
  2つの語を恒久的に扱うことになり、今回解消する用語の揺れそのものが残る。

## 結果

- `diet advice`と`advice_preference`は使えなくなる。CLIは`diet feedback`、
  プロフィールは`feedback_preference`へ変更する。
- 旧DB名はマイグレーションと旧スキーマの回帰テストにだけ残す。
