# HTMLレポートは面ではなく罫線で構造を作り、系列色は実測と参照の2色に固定する

- ステータス: 承認済み
- 日付: 2026-07-25

HTMLレポートは、カード・影・グラデーションで区画を作らず、罫線・余白・字組みだけで
構造を表す紙の資料として組む。グラフの系列色は「実測＝青、目標や移動平均などの
参照系列＝橙」の2色に固定し、他の色は使わない。汎用ダッシュボードの見た目を避け、
色数を絞ることで色が識別以外の意味を持たないようにするため。

## 検討した代替案

区画ごとのカードと影は要素の境界を強く示せるが、全要素が同じ箱に入ると階層が消え、
どの数値が重要かをタイポグラフィで示せなくなるため採用しない。系列ごとに色を増やす
案も、色が3つを超えると色覚特性のある読み手で隣接色の判別が保証できず、凡例への依存が
強まるため採らない。系列が足りない場合は色を足さず、図を分ける。

## 結果

- 2色は`dataviz`スキルの検証スクリプトで明暗両モードとも全項目を通す
  （明: 紙面 `#faf9f6` に `#2a78d6` / `#eb6834`、暗: `#141413` に `#3987e5` / `#d95926`）。
  色を変えるときは再検証する。
- 推定範囲の帯は系列ではなく装飾として扱い、凡例とツールチップから除く。
- 系列が1つの図には凡例を置かない。図の見出しが系列名を兼ねる。
- 期間内に記録が1件もない図は、空の格子ではなく文で置き換える。
