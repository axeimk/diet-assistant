# HTMLレポートはChart.jsを埋め込んだ単一の静的ファイルとして生成する

- ステータス: 承認済み
- 日付: 2026-07-25

日次・週次のHTMLレポートは、生成時点のデータ、CSS、JavaScript、Chart.jsを埋め込んだ
自己完結する単一ファイルとして生成する。ローカルサーバーを必要とせずオフラインで閲覧でき、
ツールチップ・系列切替・レスポンシブ表示を保守しやすく実現できるため、この構成を選ぶ。

## 検討した代替案

動的なローカルWebアプリは常に最新のDBを参照できる一方、サーバーの起動・終了管理が必要になる
ため採用しない。uPlot、Observable Plot、Apache ECharts、Vega-Lite、Plotly、グラフの自作も
検討したが、今回必要な操作性と実装・配布サイズ・保守負担の均衡からChart.jsを採用する。
