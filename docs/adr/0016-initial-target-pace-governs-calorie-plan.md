# 当初目標ペースをカロリー計画の基準として固定する

- ステータス: 承認済み
- 日付: 2026-07-29

目標の途中で計画を再計算しても、カロリー計画は開始時の体重差と当初期間から求めた
当初目標ペース、および赤字の25%上限を基準にする。直近体重から期限までの
現在必要ペースと、前後7日平均から求める実績ペースはレポートの参考値として分離し、
早期達成が見込まれても現在必要ペースを理由にカロリー計画を自動的に緩めない。

## 検討した代替案

- **再計算のたびに現在必要ペースへカロリー計画を合わせる** — 現在地には追従するが、
  計画より先行したときに摂取目標が自動的に緩み、当初の目標達成方針が意図せず変わる。

## 結果

- `plans.target_weekly_weight_change`は後方互換のため列名を維持しつつ、
  当初目標ペースを保存する。
- 日次・週次とも実績ペースは直近7日平均とその前の7日平均の差から求め、
  測定数とともに表示する。
